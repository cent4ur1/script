# macOS script 
Install script for macOS

```shell
git clone https://github.com/cent4ur1/script.git;cd script;chmod +x start.sh;./start.sh
```
# Arch Linux

```shell
git clone https://github.com/cent4ur1/script.git;cd script;chmod +x arch.sh;./arch.sh
```
