# macOS
This setup uses AeroSpace (default; no SIP changes needed) with yabai/skhd as an optional alternative, requiring SIP to be disabled.
```shell
git clone https://github.com/cent4ur1/script.git; cd script/macos/; chmod +x setup.sh; ./setup.sh
```
